# Compass-Gait Relaxed-Space Cycling-Signature Pipeline

End-to-end reproduction of the compass-gait row of the manuscript: a learned
encoder `E_theta` is trained on the relaxed hybrid semiflow, the canonical
limit-cycle rollout is embedded through the trained encoder, David Hien's
`CyclingSignatures.jl` computes the `H_1` cycling signature over a
(cubical cover scale, sphere-bundle cover radius) grid, and the heatmap
figure is rendered.

The encoder is the generic Section-4 residual MLP
`E(x) = pad(x, d) + MLP(x)` initialised near the identity. It embeds the
**relaxed space** `X' = X union (G x [0,1])`, not the hybrifold
`M_H = X / ~` targeted by the original CHyLL of Teng et al. (2024). Training
follows Algorithm 1 of the manuscript: Phase I optimises E and the latent
semiflow F on five loss terms (`dyn`, `glue`, `conf`, `coll`, `utb`);
Phase II freezes E and F and trains the decoder D alone on boundary-masked
reconstruction. See `SPEC.md` for the full architecture and loss spec.

The full technical specification is in [`SPEC.md`](SPEC.md). This file is the
runbook.

## Dependencies

- **Python** environment with `torch`, `scipy`, `numpy`, `matplotlib`. On
  macOS MPS is used by default; falls back to CUDA then CPU. On Windows /
  WSL the config's `device = "mps"` is downgraded to CPU automatically.
- **Julia** (tested with 1.10) with Internet access for the first run
  (downloads `StepFunctions.jl` from
  `https://github.com/davidhien/StepFunctions.jl` and `develop`s
  `CyclingSignatures.jl` from
  `local_docs/CyclingSignatures.jl-main/CyclingSignatures.jl-main/`).

## How to run from scratch

From the repository root:

```bash
bash pipelines/compass_gait_relaxed/run_pipeline.sh
```

This runs the four steps below in order. You can also run them manually.

### Step 1 — Train the relaxed-space encoder

```bash
python scripts/train_compass.py
```

Produces `runs/compass_gait/model.pt` after 120 Phase-I epochs (E + F on
`L_dyn + L_glue + L_conf + L_coll + L_utb`) and 40 Phase-II epochs
(D alone on masked `L_recon`). Dataset is ~60k `(x_i, x_{i+1})`
supervised pairs; see `SPEC.md` for the exact loss and sampling strategy.

### Step 2 — Evaluate decoded rollout vs ground truth

```bash
python scripts/evaluate_decoded_rollout_compass.py
```

This is the gate for whether the pipeline is real: loads the trained
model, simulates a held-out rollout from a perturbed limit-cycle IC, runs
both the round-trip `D(E(x))` and the semiflow rollout `D(F^k(E(x_0)))`
against the ground truth. Outputs phase-portrait and time-trace overlays
to `figures/compass_gait/fig_compass_decoded_rollout_*.png` and numerical
metrics to `data/compass_gait/report_decoded_rollout_metrics.txt`.

### Step 3 — Export encoded lift for cycling-signature input

```bash
# 5-impact canonical rollout
python "time series/cycling_signature/prepare_compass_cs_inputs_relaxed.py"

# 20-impact converged rollout (for the second heatmap panel)
python "time series/cycling_signature/prepare_compass_cs_inputs_relaxed.py" \
    --n_impacts 20 --suffix _relaxed_n20
```

Each invocation loads `runs/compass_gait/model.pt`, simulates the canonical
compass rollout (`time series/compass gait/simulate.py`), encodes arcs (at
`s = 0`) and bridges (50 interior `s ∈ (0, 1)` samples per impact) through
the trained encoder, writes `.npy` and `.csv` artifacts, and prints a
diagnostics report to
`data/compass_gait/report_relaxed*_encoder_diagnostics.txt`.

### Step 4 — Cycling signature in Julia

```bash
julia --project="time series/cycling_signature" \
      "time series/cycling_signature/run_cycling_signature.jl" \
      --base continuous_lift_relaxed

julia --project="time series/cycling_signature" \
      "time series/cycling_signature/run_cycling_signature.jl" \
      --base continuous_lift_relaxed_n20
```

First run installs dependencies into `time series/cycling_signature/` (takes
a few minutes). Subsequent runs are fast. The sweep covers
`(boxsize, sb_radius) ∈ {0.30, 0.20, 0.10, 0.05} × {1, 2, 4}` and writes
`data/compass_gait/barcode_H1_relaxed{,_n20}.csv`.

### Step 5 — Render the heatmap figure

```bash
python "time series/cycling_signature/plot_compass_rank_heatmap.py"
```

Emits the main figure and the 3-panel appendix variant described above.

## Regenerate figures only

If `model.pt` and the Julia sweep CSVs already exist, step 4 alone is enough:

```bash
python "time series/cycling_signature/plot_compass_rank_heatmap.py"
```

## One thing to know before reading the code

The encoder is architecturally pinned to the identity on the base space:

```
E_theta(x, 0) = (x, 0)          # identity, just zero-padded
E_theta(x, s) = (x, 0) + s * MLP_theta(x, s)   # bridge (s > 0)
```

All learned geometry lives on the mapping-cylinder bridges. This is what
makes the injectivity question tractable (Remark 4.2 in the manuscript) and
what lets us compare analytic vs learned bridges without worrying about the
continuous-arc portion of the trajectory. It is also the single structural
reason the relaxed-space embedding avoids the fibre-wise collisions that
the analytic parabolic bridge suffers from: the MLP output in all 5 latent
coordinates depends on `x` as well as `s`, whereas the analytic 5th
coordinate `c * s * (1 - s)` is a function of `s` alone.
